# Logos de sponsors (estáticos)

Coloca aquí PNG/SVG con fondo transparente, nombrados con el slug del sponsor:

- `dataknow.png`
- `acme-corp.png`

El slug es el nombre del sponsor en minúsculas, sin acentos, espacios → guiones.

Prioridad en el editor de Artículos:

1. Logo subido en el portal (`logo_ai` / Storage)
2. Archivo en esta carpeta
3. `logo_url` de Notion (si es URL http válida)
